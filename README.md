# Portfolio d’Amenallah Boulakamine

Le site présente mon parcours, mes compétences et mes projets de développement. Les informations affichées se trouvent dans `src/data/portfolioData.js`.

Ouvrir `index.html` dans un navigateur ou lancer `python3 -m http.server 8000` depuis ce dossier. GitHub Pages publie le site depuis la racine de la branche `master`.
